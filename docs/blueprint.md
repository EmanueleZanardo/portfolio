# **App Name**: Portfolio Replica

## Core Features:

- Content Display: Display the original site's text, images, and other content, following the original site's design.
- Navigation Structure: Replicate the site's navigation structure including links to different pages and sections.
- Image Gallery: Display the portfolio's projects through an image gallery with high resolution images and thumbnails.
- Contact Form: Implement a contact form for visitors to send messages directly from the website.
- Responsiveness: Ensure the website is fully responsive and adapts to different screen sizes (desktop, tablet, mobile).
- Generative Design Variations (AI): Suggest alternative layouts and color schemes for the portfolio site, using generative AI as a tool to explore new design possibilities based on the content from the original website.

## Style Guidelines:

- Primary color: Electric yellow (#FFFF33) to give the portfolio a vibrant and energetic feel.
- Background color: Dark charcoal gray (#333333) to provide a stark contrast and make the electric yellow pop.
- Accent color: Neon orange (#FF9933) is used to highlight important elements such as headings and links, creating a visually striking and modern layout.
- Body text font: 'Roboto Mono' monospace font for a modern, digital feel.
- Headline font: 'Bebas Neue', a sans-serif font for the headline for a bold, impactful feel. When paired with Roboto Mono it maintains readability.
- Use simple, outlined icons in neon orange to represent various sections or functionalities.
- Clean, grid-based layout for clear hierarchy and visual balance, with a focus on negative space.
- Subtle, fast transitions and hover effects, like a quick flash of neon orange, for an engaging user experience.
